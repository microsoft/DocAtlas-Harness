# ADR-060 · 文档地图与交互精修

状态：有界实现已部署；结构导航/聊天回归通过，视觉仍待用户确认。延续英文默认、中英文切换与安静聊天首页。

## 设计

本轮完整阅读frontend-design、ui-ux-pro-max及quick-reference；针对hierarchy/animation检索。文档导航不是比例分析或因果分解，不采用搜索结果中默认的Sunburst/Treemap；只采用可折叠层级、独立列表替代、有限可见节点及真实关系连线的指导。既有地图视图未存在，不复用原型模拟数据。

色板：阅读白`#FFFFFF`、底色`#F7F9FB`、正文`#263746`、次级文字`#617183`、交互蓝`#446C91`、结构线`#DCE5EC`。
地图的章节分支用蓝/青/紫三种低饱和点缀；颜色只是辅助，完整标题、连线、层级与页码同时表示关系。保留本地Noto Sans SC，主问答15–16px，控件12–13px。

```
默认：对话内容 / 紧凑输入框
按需打开文档地图：
标题/原件名称                         关闭
查找章节        地图|列表      聚焦/缩放
章节关系画布                    选中章节
真实父子连线                    页码/子节
                               阅读原文
文档页码分布 / 当前页
```

地图为原件Reader的按需全屏工作面，不挤进聊天首屏。主PDF实例留在底下，退出地图不丢原文页码/缩放/选区；点击“阅读原文”才导航到同一source的物理页。目录无节点时显示真实空态。

## 实施范围

- 共享授权目录hook：只读分页、source/revision/hash/generation校验、失败可重试、旧响应不覆盖新source、不跨会话全局缓存。目录侧栏/地图共享当次Reader已读取节点，重复开关不重跑请求。
- 地图纯确定性布局，有限节点与深度、循环/缺失父节点保护；缩放、平移、分支展开/收起与聚焦、当前页定位；完整列表/搜索可达。未加载部分与布局裁剪明确标出，不伪造关系。
- 问题气泡按内容收缩，长问题可展开，模型/用户原文不改写。对照、错误、引用和selection gate不删减。
- 将PDF滚动位置更新与聊天shell订阅分开，避免每帧重绘整个会话；仍同步保留准确返回位置。模型流式文本不假造打字延迟。
- 初始静态加载shell先显示，重型交互模块按需加载；首次与后续加载分开测。动效只用opacity/transform，150–220ms且可中断，reduced-motion静止最终状态。
- 内容指纹文件名的公共JS/CSS/字体允许immutable浏览器缓存，重复进入无需重复传输；只在已加载静态白名单成功命中后应用。HTML/API/PDF/非指纹路径仍no-store，不缓存私人内容或放松请求授权。

## 不变与验收

不改Pi Loop/工具、持久合同、来源准入、证据归属、默认英文或用户数据。不把本地导航操作计为研究或个人Memory。地图不调用模型，不触发新的增强作业；沿用现有tree读取接口。
测真实上传/目录→地图→原PDF、搜索/展开/缩放/键盘/窄屏、再次打开不重复加载、跨会话/版本迟到、当前PDF实例不重下载。保留引用、选区与长消息完整性，并运行check.sh和浏览器回归。
