# ADR-061 · 地图章节摘要与可回看的选区问答

状态：实现及本轮定向回归完成；与ADR-062继续做整合验收。用户确认的原PDF阅读/简洁聊天布局不变。

## 体验

- 地图节点显示两行摘要预览，选中节点后在右侧阅读完整摘要；大纲模式采用同一信息层级，不把整篇摘要塞进画布。
- 摘要来自同一原件、revision、基础generation/treeHash的已完成Flash增强。区分生成摘要与短节点原文摘录；未生成、读取失败和来源变化分别提示，不用标题/关键词假造摘要。
- 无摘要时提供显式生成入口，显示预算并确认后复用已有增强作业与原键重试。打开地图、点击节点、读取历史不调用模型；摘要只辅助导航，不是Evidence。
- 用户问题气泡保留轻量原文卡片：文件名、物理页码、两至三行选中文字、展开全文及回到原PDF。长文不挤占聊天空间。
- 回答有轻量“针对所选原文”入口，可展开同一上下文并回到PDF，不要求模型重新复述原文，不把输入选区冒充回答证据。
- 发送前、待处理、已消费和历史显示使用同一原始选区；刷新后由服务端记录重建。不得依赖当前Reader选区、相邻问题、文本相似或浏览器私有缓存猜关联。

## 数据与授权

1. Canonical tree保持不可变。`enrichment-tree`增加可选的、有界摘要预览overlay，完整摘要仍从已有密封增强结果读取；旧响应没有overlay仍有效。校验基础树身份、源hash、节点id/title/page及结果hash，不把另一代增强贴到当前节点。
2. 新的独立只读question-context协议只投影已有ControlStore提交、SelectionTickets和被核验的原生消息关联，不新增内容账本、第二份会话、Note或Memory。
3. 消息关联由宿主核验的native lineage/entry membership及完成checkpoint/publication确定；运行中的问题用其确切submission/requestHash，不以“最近一次选区”推断。
4. 每次公开读取同时核对查看会话与原会话权限、源revision/representation/hash。已消费ticket的执行有效期不禁止历史阅读，但不重新激活/绑定/消费ticket。已清除提交正文时，不从ticket或原生注入中复活上下文。
5. 回原PDF只接收不透明message/submission、ticket与locator标识，从服务端选区解析canonical locator并复用原件focus。异步前后重验；不接受浏览器提供的任意quote、locator或路径作为已验证出处。
6. 明确有界缓存/响应、空结果、授权失败和跨会话迟到隔离。UI默认英文，EN/中文切换不改原文、不触发重新生成或发送。
