# ADR-055：本机 Web 打开即用

状态：已接受，2026-09-10。用户明确要求删除配对码与登录功能。

本机 CLI 固定启用 `localAccess: true`，仅监听 `127.0.0.1`。不生成配对码、不设置登录 cookie、没有登录过期时间；产品页面不含登录表单和注销按钮。服务不可用时显示重新连接，不要求验证码。

安全边界保留：

- actor/workspace 仍由服务端状态目录决定，不接受浏览器声明身份；沿用既有文档、会话、个人偏好与权限记录。
- bootstrap 直接返回原协议中的服务端身份及进程级 CSRF token，启动不调用模型。token 不进入持久文档/日志；重启后浏览器重新读取，未确认任务不自动重发。
- 写请求仍要求精确 Origin 和 CSRF；全部 API 检查 Host、loopback peer，拒绝跨站及不同端口的 same-site 浏览器请求。原始 PDF、沙箱、资源信任、文档/会话授权不变。
- 本机产品的 `/api/auth/*` 返回404，不再支持登录或注销。通用 HTTP 组件的既有配对模式仅保留为可信嵌入/兼容性接口；CLI 不开放切换开关，浏览器不能启用免登录模式。
- 既有 bootstrap 字段和协议版本不变。无新会话事件、领域库或用户画像迁移。

这不是公开网站或多用户认证方案。能连接这个本机端口的人即可使用整个本机工作区；远程使用必须依靠自己的 SSH 转发，不可接到公网或共享代理。

验收：新浏览器无 cookie 直接上传/问答/原文引用；刷新与服务重启不要求代码；缺失/伪造 CSRF、跨 Origin、same-site 异源、旧 token 被拒绝；现有持久记录保持不变。实际结果记录在执行任务板。
