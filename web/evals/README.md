# Evaluation workspace

Evaluation assets enter this tree with the product slices they gate:

- [pi-parity](pi-parity/README.md) — source-pinned native runtime preservation, durability/lifecycle, and document/code mixed-task acceptance (specification; not yet executed).
- `progressive-read/` — bounded results, completeness, latency, concurrency, text quality, and visual limits.
- `locators-and-navigation/` — revision-bound block/quote/bbox/table/figure resolution and browser round trips.
- `web-interactions/` — answer-segment citations, focus history, source scope, selection/context chips, responsive and accessibility flows.
- `claims-and-citations/` — atomic claims, support/refute relations, selector resolution, citation completeness and precision.
- `research-continuity/` — prior-work recall, re-resolution, stale/change detection, scope control, and no self-support.
- `personalization/` — adherence and strict non-interference with factual verification.
- `longitudinal/` — knowledge updates, temporal reasoning, abstention, and memory correction.

The scaffold does not include synthetic scores or placeholder fixtures. Each future fixture must identify its source/license, expected behavior, and owning milestone.
The complete test layers, metrics, and version matrix are in the
[implementation plan](../docs/implementation-plan.md#15-测试与评测总计划).
