# DocAtlas applications

The Web directory now contains a runnable, isolated interaction prototype. The product server remains an ownership scaffold.
Prototype behavior does not imply that the Pi runtime or production application API exists.

- [server](server/README.md): product composition, authenticated API, run coordination and infrastructure adapters.
- [web](web/README.md): Prototype 01, real original-PDF interaction with explicitly scripted answers.

See [the current plan](../docs/implementation-plan.md). Existing DSH startup commands remain legacy-only.
